# BlackRock Integrated Three-Statement Model

[Open the interactive dashboard](https://pratikshamadnurkar.github.io/finance-portfolio-projects/BlackRock-Three-Statement-Model/blackrock-three-statement-dashboard.html)

An interactive, standalone web presentation of an integrated BlackRock, Inc. income statement, balance sheet, and cash flow forecast. It can be opened as a web link or directly as an HTML file; it does not require an API key, a server, or an Excel installation.

## Explore the model

- Review FY2023–FY2025 reported actuals and the FY2026–FY2030 illustrative forecast.
- Change annual growth, margin, working-capital, financing, and capital-allocation assumptions. The statements, chart, and summary update from those inputs.
- Use the statement selector to inspect the linked income statement, balance sheet, and cash flow statement.
- Review model checks and source notes, including cash, equity, NCI, and balance-sheet reconciliations.
- Use **Reset base case** to restore the starting assumptions.

All figures are USD millions except per-share data and diluted shares. Forecast assumptions are editable portfolio-model inputs, not BlackRock guidance. Forecast years exclude acquisitions, FX impacts, investment gains, and fund-consolidation cash flows unless an assumption explicitly models them. Results are for educational purposes and are not investment advice.

- BlackRock, Inc. 2024 Form 10-K: [SEC filing](https://www.sec.gov/Archives/edgar/data/2012383/000119312525073384/d865271dars.pdf). Used for FY2023 comparative balance sheet and permanent-equity detail.

The dashboard's **Checks & sources** view describes the model scope and displays reconciliation results.
